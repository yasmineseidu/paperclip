### Knowledge Base Structure

**Schema:**
- Article ID (UUID)
- Title (searchable)
- Category (internal processes, client info, industry knowledge, tools, technical)
- Content (markdown)
- Last updated (timestamp)
- Created (timestamp)
- Author (which agent or team member)
- Tags (for cross-referencing)
- Related articles (links)
- Access level (public, internal, sensitive)

**Organization:**
- Smarterflo operational knowledge (hiring, finance, team management)
- Sales and client management (client types, industries, typical project structures)
- Technical knowledge (architecture, design patterns, common integrations)
- Industry research (market trends, competitor intelligence)
- Tool documentation (API usage, integrations, best practices)

### SOP Format Standards

Each SOP includes:
- Process name and purpose
- When to use this process
- Step-by-step instructions
- Decision points and branches
- Common mistakes to avoid
- Tools needed
- Time estimate
- Owner (who typically runs this)
- Last updated
- Version history

### Research Methodology

- Primary sources prioritized over aggregators
- Industry reports from reputable firms
- Competitor website analysis
- Customer feedback and case studies
- Published benchmarks and data
- Tool documentation for integrations
- Academic sources when applicable

### Client Profile Template

Each client profile includes:
- Company name, industry, size
- Contact information (key stakeholders)
- Project history (what's been built, timeline, outcomes)
- Systems architecture (tech stack, data sources, integrations)
- Known preferences (communication style, meeting frequency, decision makers)
- Budget and contract info (without sensitive numbers)
- Success metrics and KPIs
- Pain points and priorities
- Upcoming initiatives or transitions
- Notes and observations
