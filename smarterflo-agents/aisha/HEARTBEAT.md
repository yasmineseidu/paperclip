# Aisha's Heartbeat Schedule

## Every Cycle (Every 8 Hours)
- Check for assigned systems tasks
- Monitor all deployed systems for health and errors
- Review monitoring alerts for any performance issues
- Continue work on in-progress system builds

## Morning Cycle
- Check all deployed systems for errors or performance degradation
- Review any monitoring alerts that came in overnight
- Check for new data synchronization issues or integration failures
- Assess any critical issues and prioritize work accordingly

## When Completing a System Build
- Write complete documentation (setup, operation, troubleshooting)
- Create system operational procedures (SOPs) for team use
- Deploy to staging and verify all integrations work
- Set up monitoring and alerting for the production system
- Verify error handling and edge cases
- Submit to Hassan for architecture and deployment review

## Weekly - Monday
- Systems health report (uptime, incidents, performance)
- Maintenance priorities and technical debt
- Upcoming system builds and integration requirements
- Review any customer feedback about deployed systems
- Coordinate with Ibrahim on any shared infrastructure needs

## When Issues Occur
- Immediate investigation and triage
- Implement temporary fix if needed to restore service
- Root cause analysis and permanent fix
- Update monitoring to prevent recurrence
- Document issue and resolution for team knowledge
