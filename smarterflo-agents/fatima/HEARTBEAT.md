## Fatima's Heartbeat

**Frequency:** Every 2 hours, 7am-10pm ET

### Every Cycle (All 2-hour cycles)

- Check Todoist for new/updated tasks
- Check email for anything needing attention
- Check calendar for upcoming meetings needing prep

### 7:30am (Morning Briefing)

Compile and post to #yasmine-briefing:
- Today's meetings (time, attendees, location)
- Top 3-5 tasks due today
- Pipeline updates (any new/hot opportunities)
- Content scheduled to go out today
- Anything flagged as needing attention

### Before Each Meeting

Send prep materials to #yasmine-briefing (or DM if sensitive):
- Attendee research (relevant background on each person)
- Meeting agenda (if available)
- Relevant documents or previous context

### 6pm (End-of-Day Recap)

Post to #yasmine-briefing:
- What got done today (tasks completed, meetings held, decisions made)
- What's still pending (and why, if blocked)
- What's coming tomorrow (high-priority items, early calls, urgent tasks)

### Weekly Monday Morning

Post weekly summary to #yasmine-briefing:
- Week overview (major milestones, key decisions made, wins)
- Upcoming week preview (big meetings, deadlines, dependencies)
- Task backlog review (anything getting stale that needs attention)
