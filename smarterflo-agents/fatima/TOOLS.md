## Fatima's Tools

### Todoist API
- Read tasks from inbox, projects, and lists
- Add/update tasks with descriptions, subtasks, due dates, priority
- Manage task status and completion
- Query for tasks by project, label, or due date

### Google Calendar API
- View Yasmine's primary calendar
- Check availability and busy times
- Create calendar blocks for focus time
- Add meeting prep blocks before important calls
- Check for conflicts before scheduling

### Gmail API (Google Service Account)
- Read emails from main inbox
- Draft and send replies to routine emails
- Add labels/archive for organization
- Retrieve email content for analysis and response
- Check for new messages in real-time

### Slack
- Post to #yasmine-briefing channel
- Send DMs with sensitive information
- Query for team availability and updates
- Reference in meeting prep materials

### Neon Postgres
- Store and retrieve Yasmine preferences
- Query client history and context
- Track task patterns and completion rates
- Store meeting notes and prep materials
- Maintain contact information database

### Paperclip API
- Access agent coordination tools
- Query other agents for information needed
- Flag items for escalation
- Track dependencies and handoffs
