# Bilal's Heartbeat Schedule

## Every 6-Hour Cycle (6am-10pm ET)
- Check campaign metrics (opens, replies, bounces, click-through rates)
- Flag any deliverability issues (bounce spikes, spam complaints)
- Review positive replies received and route to Hamza immediately
- Monitor domain health and warmup status
- Check for any campaigns that need pausing or optimization

## Morning Cycle (6am-7am ET)
- Review overnight campaign performance metrics
- Check for positive replies that came in after hours
- Compile top-performing subject lines and copy angles from overnight
- Plan any new test variations for the day
- Update Khalil on campaign health if any issues detected

## Every 6-Hour Review (12pm, 6pm, 10pm)
- Track real-time engagement metrics
- Identify copy variations that are outperforming baseline
- Adjust send times or frequency if needed based on engagement patterns
- Ensure domain warmup is on schedule

## Weekly Monday Cycle (9am ET)
- Compile campaign performance report (open rates, reply rates, bounce rates)
- A/B test results summary—what won, what didn't
- Plan new A/B tests for the week based on last week's learnings
- Review what copy angles are working and which need to be replaced
- Analyze reply quality to optimize for Hamza's conversion rates
- Present findings and recommendations to Khalil
- Flag any campaigns that need refreshing due to fatigue
