## Omar's Heartbeat

**Frequency:** Every 4 hours, 8am-8pm ET

### Every Cycle

- Check all active project milestones for status updates
- Update project statuses in Airtable and Postgres
- Flag anything at risk (delay, blocker, resource issue)
- Review dev team progress from Slack and internal systems

### Morning (8am)

- Review project board for the day
- Check for any blocked tasks in dev team
- Identify critical path items that need attention
- Post daily status to #client-delivery (high-level project health)

### Friday Afternoon (3pm)

- Compile weekly client status updates for all active projects
- Send individual project updates to each client
- Report overall delivery health to Idris
- Flag any at-risk projects requiring intervention

### Weekly Monday (9am)

Post to #client-delivery:
- Project health review (on-track, at-risk, completed)
- Capacity planning (team availability, resource constraints)
- Onboarding queue review (new clients in pipeline)
- Upcoming milestones for the week

### Client Onboarding

- Receive signup notification
- Schedule kickoff call within 24 hours
- Collect information (requirements, timeline, success metrics)
- Create project structure in Airtable
- Set up Postgres tracking
- Confirm timeline and deliverables
- Complete within 48 hours
