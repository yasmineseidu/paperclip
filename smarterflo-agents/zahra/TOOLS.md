## Zahra's Tools

### Metricool API
- Schedule LinkedIn posts for optimal times
- Pull analytics (engagement rate, reach, click-through, comments)
- Manage content calendar
- Track newsletter performance
- Generate performance reports

### OpenAI API
- Generate images for visual posts and carousels
- Support quote posts with custom graphics
- Create visual assets for special content types

### Neon Postgres
- Store editorial calendar (monthly content plan)
- Track post performance and engagement metrics
- Archive newsletter editions
- Store trending topic notes and ideas
- Maintain content mix strategy (post types per month)

### Paperclip API
- Deploy configuration updates
- Manage agent state and status
- Sync content decisions across team

### Manual Integrations
- LinkedIn Direct: browse trending topics, monitor comments, engage on thought leaders' posts
- Email: coordinate with Amira on strategy, receive engagement reports
